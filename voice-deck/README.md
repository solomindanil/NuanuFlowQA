# VoiceDeck — презентация, которая идёт за голосом

Демо-версия инструмента для «живых» выступлений: спикер говорит — фон дышит в такт
голосу, слайды переключаются сами, когда речь доходит до их темы, а контент может
«прорастать» на слайде прямо из сказанного.

## Быстрый старт

```bash
cd voice-deck
npm install
npm run dev
```

Открой `http://localhost:5173` в **Chrome** (нужен Web Speech API), разреши микрофон
и говори. Пульт спикера: клавиша `C` на сцене или `http://localhost:5173/console.html`
во втором окне — там живой транскрипт, уверенность матчинга по каждому слайду,
подтверждение переходов и ручное управление.

Прогон без микрофона (заготовленный «монолог» из `src/asr/fake-script.ts`):

```
http://localhost:5173/?asr=fake&script=1
```

## Три контура латентности

1. **Рефлекторный (<50 мс, офлайн)** — Web Audio `AnalyserNode` → canvas-фон
   реагирует на громкость голоса. Без микрофона включается синтетический режим.
2. **Понимающий (~0.5–1 с)** — Web Speech API (ru-RU/en-US) → скользящее окно
   транскрипта → триграммный матчинг против якорных фраз и текста слайдов.
   Гистерезис и консервативные пороги: ложное переключение хуже пропущенного,
   автопредложение подтверждается через 2 секунды и отменяется одной клавишей.
3. **Генеративный (2–5 с, асинхронный)** — по команде «покажи это на слайде»
   последние 15 секунд речи превращаются в патч слайда: крупная цифра, буллет,
   цитата или мини-диаграмма. Без API-ключа работает локальный mock-генератор
   (regex-извлечение цифр), с ключом Anthropic — Claude Haiku прямо из браузера
   (ключ хранится только в localStorage, вводится на пульте).

## Управление

| Действие | Голос | Клавиши / пульт |
|---|---|---|
| Следующий слайд | «следующий слайд», «идём дальше» | `→` |
| Предыдущий | «предыдущий слайд», «вернись назад» | `←` |
| Конкретный слайд | «слайд три», «слайд номер 5» | клик по слайду на пульте |
| Принять автопереход | — (само через 2 с в авто-режиме) | `Space` |
| Отменить автопереход | — | `Esc` |
| Генерация из речи | «покажи это на слайде», «покажи цифру» | `G` |
| Авто-режим вкл/выкл | — | `A` |
| Открыть пульт | — | `C` |

## Своя колода

Колода — markdown в `decks/daily-demo.md`: слайды разделяются `---`, внутри
`# заголовок`, `- буллеты` и скрытые якорные фразы для матчинга:

```md
# Метрики недели
- Ключевые цифры спринта
<!-- anchors: метрики недели; перейдём к цифрам; статистика -->
<!-- notes: заметки спикера -->
```

Якоря — это фразы, которыми ты **обычно начинаешь** тему слайда. Чем естественнее
они совпадают с твоей речью, тем раньше слайд «подхватится».
